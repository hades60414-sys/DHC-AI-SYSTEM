# RG-V5-06｜remote-agent 命令執行威脅模型（公開摘要）

> 範圍：`remote-agent/CmdActions.cs`、`remote-agent/rag1/srcD/CmdActions.cs`、`remote-agent/mcp/ragent-mcp.cjs`。模組由 TAS Team 匯入 DAS，服務企業產品以外的用途；V5.1 **沒有修改**這些檔案。可重現的繞過清單與靜態評估原始資料屬敏感資訊，只放在受控交接位置，不放公開 repo。

## 現況（依程式）

| 面向 | 現況 |
|---|---|
| 呼叫者身分 | 控制端以 CMS 簽章／加密工作檔與代理程式配對；MCP 端（`ragent-mcp.cjs`）是本機 stdio 工具，**任何能呼叫該 MCP 的模型工作階段**都能送出工作 |
| 工具啟用 | `ragent_cmd` 在 `RAGENT_AGENT` 未設定（預設 srv-db）時**預設提供**；RAG1 需 `RAGENT_CMD=1` |
| 執行帳號 | 代理程式登入帳號，`cmd.exe /d /s /c` |
| 指令限制 | 26 條正則禁止清單（字面比對）＋「同一行同時出現唯讀來源 IP 與寫入關鍵字」即擋 |
| 唯讀來源 | 以字面比對保護，非資料庫權限或網路層強制 |
| 憑證 | `SRC_PWD` 等憑證交給子行程環境；回傳內容以字面遮蔽 `[REDACTED]` |
| 稽核 | 代理程式本機 `cmd-run.log`（指令文字經遮蔽、結果碼、耗時）；無防竄改 |
| 逾時／清理 | 預設 600 s、最多 1800 s；逾時以 `taskkill /T /F` 結束整棵程序樹 |
| 提示注入 | 工具輸出加註 UNTRUSTED 提醒；同一工作階段可讀取遠端文件（doc_qa、file_tail 等） |

## 主要威脅

1. **間接提示注入 → 遠端命令執行**（高）：模型讀到惡意文件內容後被誘導呼叫 `ragent_cmd`；預設提供且無逐次人工確認。
2. **字面禁止清單可被繞過**（高）：靜態評估顯示，屬於禁止類別的指令有多種改寫可通過比對（細節受控保存）；控制組 4/4 被擋。
3. **唯讀來源只靠字面保護**（高）：寫入可經由間接方式達成，比對看不到。
4. **憑證可外洩**（中高）：遮蔽只比對字面值，經編碼或切片的值不會被遮蔽。
5. **稽核可被改寫**（中）：本機日誌由同一帳號可寫。

## 最小權限方案（提案，需 owner 決策）

| # | 措施 | 是否改協定 |
|---|---|---|
| P1 | `ragent_cmd` 改為預設關閉，只在明確設定時提供；MCP client 端對該工具強制逐次人工確認 | 否（MCP 設定） |
| P2 | 正式環境改用 allowlist：固定腳本＋參數範本（沿用 RAG1 已有的 `ExecuteFixed` 模式），自由文字指令只在 break-glass 模式並需核准單 | 是（代理程式動作） |
| P3 | 憑證只交給固定腳本，不交給自由文字指令 | 是 |
| P4 | 唯讀來源以資料庫唯讀登入與網路規則強制，不依賴字面比對 | 否（環境） |
| P5 | 每次執行的指令摘要與結果隨簽章報告回傳，控制端以 hash chain 保存 | 是 |

## 負向測試設計（交 owner 實作於 `CmdTests.cs`）

- 控制組：禁止類別的原型指令必須被擋（現況已通過）。
- 改寫組：同一禁止類別的多種改寫（跳脫字元、變數組字、編碼、間接檔案、別名）在 P2 後必須被拒（allowlist 不可能匹配）。
- 憑證組：在 P3 後，自由文字指令的子行程環境不得含憑證變數。
- MCP 組：P1 後，未設定時 `tools/list` 不得出現 `ragent_cmd`。

## 決策需求

改變預設可用性或代理程式協定會影響 DAS 其他用途，**需模組 owner 透過 Grill-Me 決策**（HUMAN_DECISION_QUEUE：SEC-01）。V5.1 不直接移除任何既有能力。
