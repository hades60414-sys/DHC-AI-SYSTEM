# 營運週報 OPS-REPORT-v1｜合成 fixture

**全部為 SYNTHETIC 虛構資料**：組織、據點、owner、快照 ID 都是測試字串，不含真實客戶、員工或營運數據。

| 檔案 | 用途 |
|---|---|
| `合成營運明細.csv` | 兩週（2026-W42／W43）三據點營運量；`BASE` 六筆為正例，`NEG-CONFLICT` 一筆只在負例同時選取時造成乙站衝突；丙站 W43 準時完成件數刻意空白（UNKNOWN） |
| `預期主張.csv` | 14 項預期主張（值、單位、核算式、來源紀錄 ID）。取自情境規格的人工核算 oracle，不是由本引擎輸出回填 |

口徑（引擎 `server/modules/enterprise-persistence/ops-report-v1.ts` 實作）：

- 期間為 ISO 週（週一至週日，Asia/Taipei，起訖含當日）；列的期間起訖必須與週別一致。
- 空值為 UNKNOWN，不是 0；任何加總或比率含 UNKNOWN 成分即為 UNKNOWN。
- 比率以整數分數保存，最後一步四捨五入到小數二位（ROUND_HALF_UP），以「百分之一」整數（例：1667＝16.67）保存；百分點差以兩個未四捨五入比率相減。
- 同週同據點有兩筆以上紀錄＝來源衝突，受影響主張為 CONFLICT 並列出全部來源，不自動挑選。
- 守恆檢查（前週末待辦＋本週受理−本週完成＝本週末待辦）只列為異常，不修改數值。
- 人審、簽認與正式匯出不在本引擎內；所有結果都是草稿依據。
