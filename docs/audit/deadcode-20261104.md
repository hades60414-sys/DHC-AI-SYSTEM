# 死碼與過度設計稽核（2026-11-04）

- 分支：`docs/deadcode-20261104`（以 `main` @ `627c898` 為基準）
- 範圍：倉庫內所有程式碼，`vendor/`（第三方匯入）與 `web-ui/plugins/starter`（git submodule）除外
- 原則：**本報告只列出發現，不刪改任何程式**。每一項都附檔案行號與 grep 證據；證據裡的 `rg` 都是在倉庫根目錄或 `web-ui/` 執行（會另外註明）。

## 方法

| 工具 | 用途 | 備註 |
|---|---|---|
| `knip@5.66.0`（分 server／client 兩次跑，各自設定 `@/*` 別名） | 找沒人匯入的檔案、沒用到的 export、沒用到的 npm 依賴 | 容器裡沒有 `node_modules`，所以 vite／vitest 外掛關掉；knip 的結果一律再用 `rg` 複查，**沒通過 grep 複查的不列入** |
| `oxlint@1.79.0 -A all -D no-unused-vars` | 找檔案內宣告後沒用到的函式／變數 | 只列函式與有意義的變數；`catch (error)` 沒用到這類雜訊不列 |
| 自寫腳本：對 `web-ui/` 以外每支 `.js/.cjs/.mjs/.ps1/.cmd/.cs/.py` 用「檔名」和「去副檔名的主檔名」在全倉庫 `rg` | 找沒有任何地方提到的孤兒腳本 | 排除 `EXPORT-MANIFEST.txt`（它是檔案清單，什麼都會列） |
| 自寫腳本：找「函式本體只有一行轉呼叫」再算非測試呼叫者數 | 找只有一個呼叫者的包裝層 | 結果逐項人工看過 |

信心等級：**高**＝靜態分析和 grep 都找不到任何使用者；**中**＝倉庫裡找不到，但可能有倉庫外的呼叫方式（排程、手動執行）；**低**＝建議重構，不算死碼。
