# DAS V3 包裝與個資檢查

檢查日期：2026-11-04。基準：`b2b7ef0`，本機與遠端 main 一致，V3／V3.1 均已發布。此次為指定功能與公開包修補，不重新匯出整套原環境。

## 範圍與方法

- 基準 2206 個 Git 項目、7 個可達 commit、2300 個唯一歷史檔案版本；掃描工作目錄與歷史文字，包含既有掃描器原本略過的掃描程式及鎖檔。
- 使用一般規則、repo 外的組織專用名單與第二套去識別偵測器；命中逐項檢查上下文，不在報告重述真實識別值。
- 盤點 35 個二進位圖像檔：33 張 PNG／JPEG／WebP 做本機 OCR，另解析 ICNS 與 ICO 圖示容器後做 OCR。SVG 以文字掃描。圖片在傳送至模型時被附件保護層擋下，未宣稱完成逐張人工視覺覆核；OCR 可能漏字或誤認。
- 檢查 manifest：54 個技能來源均存在；規則、代理與 hook 入口均存在。另追查安裝器、健康檢查、工作區限制、外部服務設定與 Git 子模組指標。

## 發現與處理

| 發現 | 信心／影響 | 本次處理 |
|---|---|---|
| 掃描器自己的使用者白名單含員工識別碼 | 高／個資 | 從目前版本移除，保留一般示例帳號；不在文件重述識別碼 |
| 上游行動版示範截圖含個人家目錄路徑 | 高／個資 | 移除該圖片及九處嵌入引用；保留授權與必要的作者署名 |
| 掃描器漏查 macOS／Linux 家目錄路徑 | 高／檢查缺口 | 新增路徑檢查，並驗證中文標點與示例路徑不誤報 |
| 自主性 hook 綁原機工作區與 tools 路徑 | 高／功能無效 | 新增本機 `das-hooks.json`，由安裝器填 toolsRoot；工作區與續做功能明確選開，維護服務根目錄可配置 |
| Gemini hook 預設註冊，但外部依賴及白名單不齊 | 高／功能無效 | 改為 `--gemini` 選裝，提供空白白名單範本；清楚標示未附的執行器、EKB、服務與排程 |
| Codex-only 健康檢查誤要求 Claude 與停用的 PM bridge | 高／驗收誤報 | 按安裝目標檢查；舊 bridge 另以 `-CheckCodexBridge` 選查 |
| 核准服務與 Codex 規則指向原機設定 | 高／可攜性 | MCP 設定改環境變數、對話目錄取目前使用者；共享記憶改為專案配置，未設時使用專案狀態 |
| 子模組設定仍在被收錄的 web-ui 子目錄 | 高／下載缺件 | 在 Git 根目錄補正 `.gitmodules`；未自行下載或執行第三方子模組 |

其他命中包含去識別測試用的合成身分號／電話／姓名、偽造憑證、範例 IP、套件維護者聯絡方式、npm 套件名稱及誤認為電話的 commit hash；未把這些當成真實帳密刪除。此次檢查未確認有真實有效的密碼或 API token 外洩；沒有拿可疑字串去嘗試登入。

- 未安裝到實際使用者設定、未呼叫真實遠端代理、未做雲端部署或真實 Gemini 交工；以上服務仍需各使用環境完成整合驗收。

## 尚未消除的歷史資料與限制

**本次清理不會抹除 Git 歷史。** 員工識別碼、原有組織縮寫註解及已移除截圖仍可從舊 commit 讀取；舊標籤、既有 clone 與 GitHub 快取也不因新 commit 自動消失。歷史重寫／強制推送會影響既有使用者，此次未執行。若要清除歷史，需另行確認範圍、備份與協作遷移方式。

自動規則與 OCR 無法證明絕無個資，也未對歷史圖片做逐版視覺覆核。本報告是公開包內容、設定與已辨識個資的檢查，不是所有服務已可直接運作或完整應用資安稽核的保證。
