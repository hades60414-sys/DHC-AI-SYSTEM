_aiw_probe：AI 網頁驗證用的暫存資料夾

用途
  中台用 AI 工具（DHC CLI）修改內網網頁前，先把測試頁放在這裡，打開確認效果，確認完就刪掉。

這裡平常應該是空的
  只會有這個說明檔。如果看到 aiw 開頭的子資料夾，那是還沒清掉的測試頁，裡面只有測試用的假資料。

可以直接刪
  整個 _aiw_probe 資料夾隨時都可以刪，網站其他頁面都不依賴它。

安全設計
  1. 測試用的 .php 頁面上傳 30 分鐘後會自動停用（回 410），就算沒刪掉也打不開。
  2. 每次開新測試前，會先清掉一天以前留下的測試資料夾。
  3. 沒有排程，也沒有常駐程式。沒有人再用這套機制，就不會有新檔案出現。
  4. 刪除只認 aiw 開頭、而且裡面有 .aiw_owned 標記的子資料夾，碰不到網站其他檔案。

管理腳本
  srv-rag（10.255.0.16）的 C:\Users\E0000000\aiw-probe\aiw-probe.cmd
  網站搬家或換 IP 時，改這支腳本最上面的 WEBROOT、BASEURL 兩行就好。
  腳本找不到網站根目錄會直接停下來，不會猜路徑。
