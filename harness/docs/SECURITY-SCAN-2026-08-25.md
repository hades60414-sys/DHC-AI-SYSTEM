Method: manual static review because SkillSpector was not installed. Repositories were cloned without running install hooks; tracked manifests, skill instructions, scripts/hooks, download paths, credential access, process execution, deletion, telemetry, and licenses were reviewed. Release binaries were downloaded only after source review and compared with the checksums published beside the GitHub release assets.
