# 武器 ① 品味打磨(anti-slop)

把「能用但很平、很模板、很 AI」的畫面升級成有層級、有呼吸感的設計。**先講清楚要傳達的氣質,再動手**(pre-flight)。

## 1. 排版(typography)— 最快見效

- **用模組化 type scale**,別亂給字級。比例取 1.2(穩)/1.25/1.333(對比強)。例:12 · 14 · 16 · 20 · 25 · 31 · 39 · 49。一頁字級種類 ≤ 5。
- **字重要有對比**:標題 600–800、內文 400–450、次要 400 + 降彩度。別整頁 400。
- **行高**:內文 1.5–1.65;大標 1.05–1.2(越大越緊)。
- **字距(tracking)**:大標 tighter(`-0.01~-0.02em`);全大寫小標放寬(`+0.05~0.1em`);內文不動。
- **行寬**:正文 60–75 字元(`max-w-[65ch]`),別整行貫穿。
- **數字**:表格/儀表板用 `font-variant-numeric: tabular-nums` 對齊。
- **去 slop tell**:別到處塞 em-dash「—」當萬用標點;標題別用句號;避免無意義 emoji 當項目符號。

## 2. 間距與節奏(spacing)

- **用 4 / 8 的 spacing scale**(4 8 12 16 24 32 48 64 96…),所有 padding/margin/gap 從這套取,別出現 13px、27px 這種隨手值。
- **慷慨的區塊留白**:section 之間 64–96px;區塊內元素 16–24px。留白本身就是設計。
- **鄰近原則**:相關的東西靠近、不相關的拉開,用距離建立分組,別靠線/框硬切。

## 3. 對比與視覺層級(hierarchy)

- **一個畫面一個主焦點**。用「字級 + 字重 + 顏色 + 留白」四件事建立 1 級 → 2 級 → 3 級。
- **弱化次要資訊**:標籤、說明、metadata 用 gray-400/500,不要全部黑色搶戲。
- **強調靠克制**:整頁灰階 + 一個重點才會跳;到處都重點 = 沒有重點。

## 4. 顏色(color)

- **克制的 palette**:1 個主色(品牌)+ 1 套中性灰階,點綴色 ≤ 1。彩色越少越高級。
- **別用純黑純白**:背景近黑 `#0a0a0a~#111`、近白 `#fafafa~#f5f5f5`;純黑文字改 `#1a1a2e` 之類降一點。
- **對比達標**:正文對背景 ≥ 4.5:1(WCAG AA),大字 ≥ 3:1。深色介面尤其容易踩雷。
- **語意色**:成功/危險/警告固定一組,別每頁不同綠。

## 5. 版面(layout)

- **打破「永遠置中」**:適度用非對稱、網格張力、靠左對齊的內容軸,比死板置中有個性。
- **密度可調**:行銷頁要 spacious(大留白大字);儀表板/工具可 dense,但 dense ≠ 擠,仍要對齊與分組。
- **對齊**:所有東西吸附到隱形網格;不對齊是最大的廉價感來源。

## 6. 元件狀態(常被漏掉 = 半成品感)

每個會變的元件都要有:**empty(空狀態給引導,不是空白)、loading(skeleton 優於轉圈)、error(可讀的話 + 重試)、hover / focus-visible(鍵盤可達)、disabled**。

## 7. 「AI slop」常見 tell(看到就修)

- 到處圓角 + 柔陰影 + 紫藍漸層的「generic SaaS」感 → 收斂陰影、慎用漸層。
- 一排等寬卡片、每張長一樣、無層級 → 給主卡更大權重。
- CTA 一頁好幾顆同等強度 → 主 CTA 只留一顆,其餘降級為次要/文字鈕。
- 置中 + 置中 + 置中 → 換軸線、加非對稱。
- 假資料太整齊(全是 +2.1% +3.4%)→ 真實感資料或標「示意」。
